# Книга відгуків (Guest Book) — Базовий вебдодаток

Простий вебдодаток на базі Jakarta Servlet API, Jetty 11, H2 Database та JDBC для управління книгою відгуків.

## Технічний стек
- **JDK:** 21
- **Maven:** 3.9+
- **Сервер розробки:** Jetty Maven Plugin (v11.0.20)
- **База даних:** H2 Database (File mode)
- **Бібліотеки:** Jackson Databind (JSON), SLF4J + Logback (Логування)
